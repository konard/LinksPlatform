# Turing Completeness Proof - Code Examples

This directory contains practical code examples demonstrating how Triggers can emulate various Turing-complete computational models.

## Examples Included

1. **MarkovAlgorithmExample.cs** - String rewriting using Markov algorithm rules
2. **TuringMachineExample.cs** - Simple Turing machine emulation
3. **SKICalculusExample.cs** - SKI combinator calculus
4. **YCombinatorExample.cs** - Fixed-point combinator for recursion
5. **LambdaCalculusExample.cs** - Lambda calculus with β-reduction

## Running Examples

Each example can be run independently to demonstrate the concept. The examples use a simplified trigger API to illustrate the principles clearly.
