# Code Transformations Database

This directory contains a community-editable database of code transformation examples across different platforms, languages, frameworks, and environments.

## Structure

Each transformation is documented in its own markdown file, organized by category:

- **`string/`** - String manipulation operations (lowercase, uppercase, trim, split, etc.)
- **`conversion/`** - Data type conversions (string to int, int to string, etc.)
- **`collections/`** - Collection operations (filter, map, reduce, sort, etc.)
- **`file/`** - File system operations (read, write, copy, delete, etc.)
- **`encoding/`** - Encoding and serialization (Base64, URL encoding, JSON, etc.)

## Quick Start

### Finding a Transformation

1. Browse the category folders above
2. Each transformation file contains multiple implementations across different platforms/languages
3. Look for the platform/language combination that matches your needs

### Example: String to Lowercase

See [`string/to-lowercase.md`](string/to-lowercase.md) for examples in:
- C# (.NET)
- Python
- JavaScript
- Java
- Go
- Rust
- PHP
- Bash

Each example includes:
- Complete, working code
- Platform and version information
- Important notes and gotchas
- Links to official documentation

## Contributing

We welcome contributions! To add a transformation:

1. Check if a similar transformation already exists
2. Follow the template structure in [`code-transformations-contributing.md`](../code-transformations-contributing.md)
3. Include complete, tested code examples
4. Specify all version information
5. Add references to official documentation

See the full [Contributing Guidelines](../code-transformations-contributing.md) for detailed instructions.
