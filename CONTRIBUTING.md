# Contributing to LinksPlatform

We welcome contributions to the LinksPlatform project! This document provides guidelines for contributing.

## Code of Conduct

This project has adopted the [.NET Foundation Code of Conduct](https://dotnetfoundation.org/about/policies/code-of-conduct). By participating in this project, you agree to abide by its terms.

## How to Contribute

1. **Fork the repository** and create your branch from `master`.
2. **Make your changes** and ensure they follow the project's coding style.
3. **Test your changes** to ensure they work as expected.
4. **Commit your changes** with clear and descriptive commit messages.
5. **Submit a pull request** with a clear description of your changes.

## Reporting Issues

If you find a bug or have a suggestion for improvement:

1. Check if the issue already exists in the [issue tracker](https://github.com/konard/LinksPlatform/issues).
2. If not, create a new issue with a clear description of the problem or suggestion.
3. Provide as much relevant information as possible, including steps to reproduce bugs.

## Questions?

If you have questions about contributing, feel free to ask in the [discussions](https://github.com/konard/LinksPlatform/discussions) or create an issue.

Thank you for contributing to LinksPlatform!
